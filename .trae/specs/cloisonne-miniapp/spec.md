# 掐丝珐琅纹样生成小程序 - 产品需求文档

## Overview
- **Summary**: 一款微信小程序，用户通过拍照或上传图片，AI 自动将图片转化为掐丝珐琅（景泰蓝）风格纹样，支持金属丝轮廓线稿与带釉料质感的效果图两种输出，并提供配色微调、导出、收藏等工具。
- **Purpose**: 以数字化方式传播掐丝珐琅非遗文化，降低手工掐丝珐琅创作门槛，让普通用户也能快速生成可用于实际手工制作的掐丝珐琅纹样。
- **Target Users**: 掐丝珐琅手工艺爱好者、非遗文化传播者、设计师、中小学生美育课堂、对传统工艺感兴趣的普通用户。

## Goals
- 一键将任意图片（手绘草图、花卉、传统纹样、人物剪影、几何图案）转化为掐丝珐琅风格纹样。
- 输出可直接用于手工制作的金属丝轮廓线稿（黑白线稿）。
- 输出带金属丝与釉料质感的完整掐丝珐琅效果图。
- 提供传统珐琅配色（宝蓝、石青、朱红、石绿、鹅黄等）及自定义配色能力。
- 收藏和管理历史生成记录。
- 科普掐丝珐琅非遗文化。

## Non-Goals
- 不提供实际的掐丝珐琅物理制作教学视频。
- 不提供 3D 建模或 AR 预览。
- 不提供社区分享、用户评论等社交功能（首版）。
- 不支持视频输入，仅处理静态图片。
- 不提供多人协作编辑。

## Background & Context
- 掐丝珐琅（景泰蓝）是国家级非物质文化遗产，核心工序为"掐丝"（用铜丝弯折出图案轮廓）和"点蓝"（在封闭区域填色釉料）。
- 传统手工掐丝需要先设计线稿，再手工弯折铜丝，门槛较高。本小程序通过 AI 图像处理自动生成线稿与配色方案，辅助创作。
- 技术决策：采用微信云开发（云函数 + 云存储 + 云数据库），AI 图像处理使用 OpenCV 在云函数中本地完成，无需第三方付费 API。

## Functional Requirements

### FR-1: 首页
- **FR-1.1**: 首页提供"拍照上传"和"相册上传"两个功能入口。
- **FR-1.2**: 首页展示掐丝珐琅非遗文化简短科普介绍。
- **FR-1.3**: 首页展示小程序生成的纹样样例（案例展示）。

### FR-2: 图片预处理
- **FR-2.1**: 上传图片后自动执行图像抠图，分离主体纹样与背景。
- **FR-2.2**: 自动提取轮廓线条，适配掐丝"丝"的金属线条。
- **FR-2.3**: 自动降噪，清理照片杂点（手绘草稿污渍、实物照片杂色）。
- **FR-2.4**: 支持处理以下类型图片：手绘草图、花卉、传统纹样、人物剪影、几何图案。

### FR-3: AI 纹样生成（核心）
- **FR-3.1**: 生成金属丝轮廓：模拟铜丝弯折的连续线条（掐丝工序效果）。
- **FR-3.2**: 生成分区色块：将图形分割成封闭区域（点蓝填色区域）。
- **FR-3.3**: 提供配色推荐：传统珐琅配色（宝蓝、石青、朱红、石绿、鹅黄等），也支持自定义配色。
- **FR-3.4**: 提供两种导出预览：
  - 线稿版：只有金属掐丝轮廓（直接打印用于手工描图）。
  - 效果图版：完整掐丝珐琅成品预览（金属丝 + 釉料质感）。

### FR-4: 工具箱
- **FR-4.1**: 纹样微调：调整线条粗细、色块数量。
- **FR-4.2**: 配色面板：预设传统珐琅色卡，支持自定义换色。
- **FR-4.3**: 导出：PNG 效果图 / 黑白线稿图，可保存到相册。
- **FR-4.4**: 纹样收藏：保存历史生成记录。

## Non-Functional Requirements
- **NFR-1**: 单张图片从上传到生成结果的总耗时（含预处理 + 纹样生成）应在 15 秒以内（云函数冷启动除外）。
- **NFR-2**: 处理图片最大尺寸不超过 4096×4096，单张图片大小不超过 10MB。
- **NFR-3**: 小程序界面适配主流手机屏幕（宽度 320px-430px），UI 风格体现传统珐琅美学（深色底 + 金属色 + 宝石色）。
- **NFR-4**: 云函数图像处理使用 OpenCV，不依赖第三方付费 AI API。
- **NFR-5**: 代码结构清晰，云函数与小程序前端分离，便于后续维护与扩展。

## Constraints
- **Technical**: 
  - 前端为微信小程序原生框架（WXML + WXSS + JS），不使用 uni-app/Taro。
  - 后端为微信云开发，云函数使用 Node.js + opencv4nodejs 进行图像处理。
  - 数据存储使用云数据库（收藏记录）和云存储（生成的图片）。
  - 小程序 AppID 暂用测试号，后续可替换。
- **Business**:
  - 首版不涉及付费功能。
- **Dependencies**:
  - 依赖微信云开发环境。
  - 依赖 opencv4nodejs 云函数运行时。

## Assumptions
- 用户已安装微信并能使用小程序。
- 用户授权小程序使用相机和相册权限。
- 云开发环境已开通且配额充足。
- opencv4nodejs 可在云函数运行时正常工作（若运行时不支持，回退为纯前端 Canvas 处理方案）。

## Acceptance Criteria

### AC-1: 首页功能入口
- **Type**: `rule`
- **Given**: 用户打开小程序
- **When**: 进入首页
- **Then**: 页面显示"拍照上传"和"相册上传"两个按钮，显示掐丝珐琅科普介绍，展示至少 3 个纹样样例
- **Pass Condition**: 首页包含两个上传入口、科普文案、案例展示区
- **Evidence**: 首页 WXML 渲染包含对应元素

### AC-2: 图片上传
- **Type**: `rule`
- **Given**: 用户在首页点击上传入口
- **When**: 选择拍照或从相册选取图片
- **Then**: 图片上传成功并跳转到处理流程
- **Pass Condition**: 调用 wx.chooseMedia 成功获取图片并上传至云存储
- **Evidence**: 云存储中出现上传的图片文件

### AC-3: 图像抠图
- **Type**: `rule`
- **Given**: 图片已上传
- **When**: 执行预处理
- **Then**: 主体纹样与背景分离，输出透明背景的主体图
- **Pass Condition**: 抠图后背景为透明（alpha=0），主体保留
- **Evidence**: 云函数返回的抠图结果 alpha 通道在背景区域为 0

### AC-4: 轮廓线条提取
- **Type**: `rule`
- **Given**: 抠图完成
- **When**: 执行线条提取
- **Then**: 输出主体的连续轮廓线条图
- **Pass Condition**: 线条图中轮廓为黑色连续线条，其余为白色或透明
- **Evidence**: Canny 边缘检测 + 形态学处理生成的线条图

### AC-5: 降噪处理
- **Type**: `rule`
- **Given**: 原始图片含杂点
- **When**: 执行降噪
- **Then**: 杂点被清理，主体轮廓更清晰
- **Pass Condition**: 降噪后图片杂点数量少于原图
- **Evidence**: 高斯模糊/中值滤波处理后效果

### AC-6: 多类型图片支持
- **Type**: `rule`
- **Given**: 输入手绘草图/花卉/传统纹样/人物剪影/几何图案
- **When**: 执行完整处理流程
- **Then**: 均能输出合理的掐丝珐琅纹样
- **Pass Condition**: 五种类型图片各生成至少一个线稿和效果图
- **Evidence**: 测试用例覆盖五种类型

### AC-7: 金属丝轮廓生成
- **Type**: `rule`
- **Given**: 预处理完成
- **When**: 执行纹样生成
- **Then**: 生成模拟铜丝弯折的连续金属丝轮廓
- **Pass Condition**: 轮廓线条具有金属质感（渐变/高光），连续不断裂
- **Evidence**: 线稿版图中线条呈现金属色渐变

### AC-8: 分区色块生成
- **Type**: `rule`
- **Given**: 预处理完成
- **When**: 执行纹样生成
- **Then**: 图形被分割为封闭的色块区域
- **Pass Condition**: 每个封闭区域填充单一颜色，区域之间由金属丝分隔
- **Evidence**: 效果图中色块边界清晰，无颜色溢出

### AC-9: 配色推荐
- **Type**: `rule`
- **Given**: 纹样生成完成
- **When**: 查看配色
- **Then**: 提供传统珐琅配色方案，包含宝蓝、石青、朱红、石绿、鹅黄等
- **Pass Condition**: 预设色卡至少包含 5 种传统珐琅色，可一键应用
- **Evidence**: 配色面板显示预设色卡

### AC-10: 自定义配色
- **Type**: `rule`
- **Given**: 用户在配色面板
- **When**: 选择自定义颜色
- **Then**: 可替换任意色块的颜色
- **Pass Condition**: 色块颜色根据用户选择更新并实时预览
- **Evidence**: 颜色选择器回调更新色块填充

### AC-11: 线稿版导出
- **Type**: `rule`
- **Given**: 纹样生成完成
- **When**: 选择线稿版预览并导出
- **Then**: 导出仅含金属掐丝轮廓的黑白线稿图
- **Pass Condition**: 导出图片为黑白线稿，可保存到相册
- **Evidence**: saveImageToPhotosAlbum 成功保存线稿 PNG

### AC-12: 效果图版导出
- **Type**: `rule`
- **Given**: 纹样生成完成
- **When**: 选择效果图版预览并导出
- **Then**: 导出含金属丝+釉料质感的完整掐丝珐琅效果图
- **Pass Condition**: 导出图片包含金属丝和彩色釉料，可保存到相册
- **Evidence**: saveImageToPhotosAlbum 成功保存效果图 PNG

### AC-13: 纹样微调
- **Type**: `rule`
- **Given**: 纹样已生成
- **When**: 调整线条粗细或色块数量滑块
- **Then**: 纹样实时更新
- **Pass Condition**: 线条粗细和色块数量随滑块变化，预览同步更新
- **Evidence**: 滑块 change 事件触发重新渲染

### AC-14: 纹样收藏
- **Type**: `rule`
- **Given**: 用户对生成结果满意
- **When**: 点击收藏按钮
- **Then**: 纹样保存到收藏列表
- **Pass Condition**: 收藏记录写入云数据库，收藏页可查看历史记录
- **Evidence**: 云数据库 collection 新增记录

### AC-15: 收藏记录管理
- **Type**: `rule`
- **Given**: 存在收藏记录
- **When**: 进入收藏页
- **Then**: 展示历史生成记录列表，可查看详情
- **Pass Condition**: 收藏列表展示缩略图和生成时间，点击可查看大图
- **Evidence**: 收藏页 WXML 列表渲染

### AC-16: UI 视觉质量
- **Type**: `rubric`
- **Dimension**: 界面视觉效果体现掐丝珐琅非遗美学
- **Scale**: 1-5
- **Anchors**: 1 = 简陋无设计感；3 = 基本可用但缺乏珐琅特色；5 = 深色底+金属色+宝石色，精美且主题鲜明
- **Pass Threshold**: >= 4
- **Evidence**: 截图评审首页、处理页、工具箱页

### AC-17: 图像处理效果质量
- **Type**: `rubric`
- **Dimension**: 生成的掐丝珐琅纹样整体效果
- **Scale**: 1-5
- **Anchors**: 1 = 线条断裂/色块混乱；3 = 基本可用但细节粗糙；5 = 线条流畅连续、色块分区清晰、配色协调，接近真实掐丝珐琅效果
- **Pass Threshold**: >= 4
- **Evidence**: 生成结果图评审

### AC-18: 处理性能
- **Type**: `rubric`
- **Dimension**: 图片处理响应速度
- **Scale**: 1-5
- **Anchors**: 1 = 超过 30 秒；3 = 15-30 秒；5 = 10 秒以内
- **Pass Threshold**: >= 4
- **Evidence**: 云函数执行日志耗时统计
